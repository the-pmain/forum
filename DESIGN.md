# Financial Navigator — visual system

Inherited from `Financial_Navigator_Cards_and_Small_Credit.html`. This is an operate surface: a directory you scan, filter, and maintain.

## Scene

A daylight desktop workspace for reviewing banks and borrowing products across six European markets. Light paper canvas, a navy navigation rail, teal as the only action colour.

## Tokens

- Ink `#182a39`, muted `#687b89`, nav `#112738`, teal `#087e78`, canvas `#f3f6f7`, line `#dde5e9`
- Type: Inter / Segoe UI / Arial. Display 33px / -1.1px. Body 14px.
- Radius 15px on cards, 9px on controls. Shadows offset and soft (`0 10px 28px #1831410c`).

## Layout

Fixed 236px sidebar, sticky frosted toolbar, category tiles, filter panel, then cards or table. Provider detail is a right-hand drawer. Admin sign-in and help are quieter sibling pages in the same materials.

## Motion

Short hover lifts on tiles and cards. No decorative entrance choreography. Respect `prefers-reduced-motion`.
